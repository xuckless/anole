# Object storage (S3)

Up: [index](index.md). Related: [resilience](resilience.md) (retries and breaker on by default here), [http client](http-client.md) (it runs on the same core client).

`anole.s3` is a pure Zig client for S3-compatible stores (AWS S3, Cloudflare R2, MinIO, Backblaze B2, Supabase Storage) with its own SigV4 signer, streaming uploads and downloads, and presigning. Needs `-Ds3` ([config-cli](../config-cli.md#feature-flags-and-profiles)). Full docs: docs/storage.md. Tests: src/s3/s3_test.zig, src/s3/live_test.zig.

Use:
- `anole.App.s3` (src/server.zig): `app.s3(.{})` returns `*anole.s3.Client`
- `anole.s3.Client`: `default`, `bucket`, `with`, `closeIdle` (src/s3/root.zig)
- `anole.s3.Bucket`: `get`, `optional`, `open`, `serve`, `head`, `exists`, `put`, `upload`, `delete`, `deleteMany`, `list`, `iterate`, `copy`, `presign`, `multipart`, `with` (src/s3/root.zig)
- `anole.s3.Options`, `anole.s3.CallOptions`, `anole.s3.GetOptions`, `anole.s3.ServeOptions`, `anole.s3.PutOptions`, `anole.s3.Body`, `anole.s3.Stored`, `anole.s3.Object`, `anole.s3.Meta`, `anole.s3.ListOptions`, `anole.s3.PresignMethod`, `anole.s3.PresignOptions`, `anole.s3.Multipart` (src/s3/root.zig)
- `anole.s3.Upload` (`write`, `waitWritable`, `finish`, `abort`, `deinit`) (src/s3/upload.zig); `anole.s3.Download` (`reader`, `pipe`, `deinit`) (src/s3/download.zig)
- `anole.s3.testing.FakeServer` (src/s3/testing.zig)

## Setup, put and serve

```zig
const files = try app.s3(.{});    // AWS_* variables, S3_BUCKET

fn upload(state: *State, req: *anole.Request, res: *anole.Response) !void {
    const stored = try state.files.default().put(req, "avatars/1.png", .request, .{}); // the request body goes to S3
    res.status = .created;
    try res.json(.{ .etag = stored.etag });
}

fn avatar(state: *State, req: *anole.Request, res: *anole.Response) !void {
    _ = try state.files.default().serve(req, res, "avatars/1.png", .{}); // Range, ETag and 304 included
}
```

`app.s3(.{})` reads what AWS SDKs read: `AWS_ENDPOINT_URL_S3` / `AWS_ENDPOINT_URL`, `AWS_REGION`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_SESSION_TOKEN`, `AWS_PROFILE`, and `S3_BUCKET` (the default bucket). Credentials chain: environment, shared credentials file, then (AWS endpoints only) web identity, container endpoint, EC2 IMDSv2; `.credentials = .anonymous` for public buckets. `default()` is the `S3_BUCKET` bucket, `bucket(name)` another.

`put` bodies: `.{ .bytes = b }`, `.{ .reader = .{ .reader = r, .len = n } }`, `.{ .file = path }`, `.request`. `PutOptions`: `content_type` (from the extension by default), `cache_control`, `content_disposition`, `content_encoding`, `metadata`, `storage_class`, `if_absent`, `if_match`, `headers`.

## Reads

`get` returns the whole object (`Object.body`, at most `max_object_bytes`, 16 MiB); `optional` returns null for a missing key; `open` streams (src/s3/s3_test.zig, fixture replaced):

```zig
var dl = try state.files.default().open(req, "big.bin", .{});
defer dl.deinit();
var out: std.Io.Writer.Allocating = .init(req.arena);
const n = try dl.pipe(&out.writer);
```

`serve` forwards Range and conditional headers, passes 200/206/304/412/416 through and streams without buffering. A missing key is `error.NotFound` before anything is sent.

## Push uploads

From src/s3/s3_test.zig, with the test fixture replaced by `state.files` and `req` (any context works: `req`, a `*Job`):

```zig
var up = try state.files.default().upload(req, "exact.bin", .{});
defer up.deinit();
var off: usize = 0;
while (off < data.len) {
    const n = @min(64 * 1024, data.len - off);
    _ = try up.write(req, data[off..][0..n]);
    off += n;
    try up.waitWritable(req, null);
}
const stored = try up.finish(req);
```

`write` returns at once: `.ok`, `.busy` (taken, but wait with `waitWritable` before more), or `error.ServiceUnavailable` code `upload_full` (nothing taken).

## Presigned URLs

From src/s3/live_test.zig, fixture replaced as above:

```zig
const put_url = try state.files.default().presign(req, .put, key, .{ .content_length = 5 });
const get_url = try state.files.default().presign(req, .get, key, .{});
```

Methods `.get`, `.put`, `.head`, `.delete`, `.upload_part` (`upload_id`, `part_number`). `expires` defaults to 15 min, at most 7 days. A PUT can sign `content_type` and an exact `content_length`. No POST policies.

Traps:
- Upload a request body with `put(req, key, .request, .{})`, never by reading the body into memory first. `limits.body_max` applies (`error.BodyTooBig`, 413).
- After `write` returns `.busy`, call `waitWritable` before writing again; ignoring it ends in `upload_full` ([writes return once buffered](../runtime.md#writes-return-once-buffered)).
- `abort()` or `deinit()` before `finish` aborts the multipart upload; add an `AbortIncompleteMultipartUpload` lifecycle rule to every bucket you upload to (docs/storage.md#uploads).
- Retries are **on** (3 attempts) and a breaker is on; `with(.{ .retry = false })` for one try. Readiness is off by default on purpose.
- No credentials at start fails the start, naming every source tried.
- Not supported: bucket admin, ACLs, tagging, object lock, SSE-C, copies over 5 GiB, POST policies, S3 Express.
- Tests without Docker: `anole.s3.testing.FakeServer.start(gpa, io)`, then `anole.s3.Client.init(gpa, io, .{ .endpoint = fake.url(), .bucket = "b", .credentials = fake.credentials() })` ([testing](../testing.md)).
